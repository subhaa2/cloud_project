To Test Whiteboard Feature:
1. Open a cmd and go to Whiteboard folder of the project.
3. Run npm install. Terminal should download all the dependencies and create node_modules folder.
4. Run npm start. Terminal should show "Server running on port 8080".
5. Open whiteboard.html file. Terminal should show "New client connected".

To Note:
- Make sure you have Node.js and npm installed.
- If unable to run npm start, ensure terminal is in admin cmd.
